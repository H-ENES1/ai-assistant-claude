```ts
import i18n from "i18next";
import { initReactI18next } from "react-i18next";
import LanguageDetector from "i18next-browser-languagedetector";
import en from "./locales/en.json";
import tr from "./locales/tr.json";
import de from "./locales/de.json";
import fr from "./locales/fr.json";

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: en },
      tr: { translation: tr },
      de: { translation: de },
      fr: { translation: fr },
    },
    fallbackLng: "en",
    interpolation: { escapeValue: false },
  });

export default i18n;
```
Import this file once in `main.tsx` before rendering the app.

**3. Create locale files**
Create `src/locales/en.json` as the source, plus `tr.json`, `de.json` and `fr.json`. All four must have identical keys, grouped by screen, for example `login.title` and `login.submit`. Keep placeholders such as `{{name}}` unchanged in every language.

**4. Replace hardcoded strings**
```tsx
const { t } = useTranslation();

  <option value="fr">Français</option>

```

**7. Catch missing keys**
Turn on i18next's `debug` option in development, or write a short script that compares the key sets across the four JSON files and fails on any mismatch.
