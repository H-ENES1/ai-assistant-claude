# Işığın Bile Kaçamadığı Yer: Kara Delikler

Bir taşı yukarı attığınızda geri düşer. Yeterince hızlı atarsanız (Dünya için saniyede yaklaşık 11 km) bir daha geri gelmez. Peki kaçış hızının ışık hızını aştığı bir yer olsaydı? İşte kara delik tam olarak budur: Kütlesi o kadar küçük bir hacme sıkışmıştır ki hiçbir şey, ışık bile, oradan kaçamaz.

## Nasıl Oluşur?

Güneş'ten kabaca 20 kat ve daha ağır yıldızlar ömürlerinin sonunda yakıtlarını tüketir. Çekirdeği dışarı doğru iten basınç ortadan kalkınca kütleçekimi kazanır ve çekirdek kendi üzerine çöker. Dış katmanlar süpernova patlamasıyla uzaya saçılırken geride bir kara delik kalabilir. Karşılaştırma için: Güneş'in kara delik olması için yaklaşık 3 km yarıçapa, Dünya'nın ise bir bilye boyutuna (yaklaşık 9 mm) sıkıştırılması gerekirdi.

## Olay Ufku: Dönüşü Olmayan Sınır

Kara deliğin "yüzeyi" aslında katı bir yüzey değildir. Olay ufku denen bu sınırı geçen hiçbir şey geri dönemez. 1916'da Karl Schwarzschild, Einstein'ın genel görelilik denklemlerinden bu yarıçapı hesapladı. Ufka yaklaşan bir cisim, kütleçekimi farkı yüzünden boylamasına çekilip uzar. Fizikçiler buna şakayla karışık "spagettileşme" der. Uzaktaki bir gözlemciye göre ise ufka düşen cismin zamanı giderek yavaşlıyor gibi görünür.

## Türleri

- **Yıldız kütleli kara delikler:** Birkaç ile onlarca Güneş kütlesi arasındadır.
- **Süper kütleli kara delikler:** Milyonlarca, hatta milyarlarca Güneş kütlesindedir ve neredeyse her büyük galaksinin merkezinde bulunur. Samanyolu'nun merkezindeki Sagittarius A* yaklaşık 4 milyon Güneş kütlesindedir.
- **Orta kütleli kara delikler:** Varlıklarına dair kanıtlar artıyor ama hâlâ araştırılıyorlar.

## Görünmeyeni Nasıl Görüyoruz?

Kara delikleri doğrudan göremeyiz ama çevrelerine yaptıkları etkiyi ölçebiliriz. Sagittarius A* çevresindeki yıldızların yörüngeleri onlarca yıl izlendi. Bu çalışma 2020 Nobel Fizik Ödülü'nü getirdi. 2015'te LIGO, birleşen iki kara deliğin yaydığı kütleçekim dalgalarını ilk kez yakaladı. 2019'da Olay Ufku Teleskobu, M87 galaksisindeki kara deliğin "gölgesini" görüntüledi. 2022'de de kendi galaksimizin merkezindeki kara deliğin görüntüsünü yayımladı.

## Kara Delikler Sonsuz mu?

Stephen Hawking, kuantum etkiler nedeniyle kara deliklerin çok zayıf bir ışıma yaydığını ve akıl almaz uzunlukta sürelerde buharlaşabileceklerini öne sürdü. Bu ışıma henüz gözlenmedi. Yine de içine düşen bilginin akıbeti, yani "bilgi paradoksu", fiziğin en büyük açık sorularından biri olmaya devam ediyor.

Kara delikler bir zamanlar yalnızca denklemlerdeki bir tuhaflıktı. Bugün ise evrenin en uç laboratuvarları olarak görülüyorlar.

## r33

**İSTEM:**

TypeError: Cannot read properties of undefined (reading 'map') — how do I fix this?

### r33 · A

This error means you called `.map()` on something that is `undefined` rather than an array. The fix is to find out **why** the value is undefined and then either fix the source or guard against it.

## 1. Find which variable is undefined

Look at the line in the stack trace. If it says `data.items.map(...)`, then `data.items` is undefined. Log it right before that line:

```js
console.log('items:', data.items);
```

## 2. Common causes and fixes

**Async data not loaded yet (very common in React)**

The component renders before the fetch finishes:

```jsx
const [items, setItems] = useState();      // undefined on first render
// ...
items.map(i => <li key={i.id}>{i.name}</li>) // crashes
```

Fix: start with an empty array.

```jsx
const [items, setItems] = useState([]);
```

**Wrong property path in the API response**

You expected `response.data` but the array is actually at `response.data.results`. Log the full response and check its shape:

```js
const res = await fetch(url);
const json = await res.json();
console.log(json);           // inspect the real structure
setItems(json.results);      // use the correct key
```

**Prop not passed from the parent**

```jsx
<List />                      // forgot items={...}
```

Fix: pass the prop, or give it a default:

```jsx
function List({ items = [] }) { ... }
```

**Function that forgot to `return`**

```js
function getItems() { const arr = [1, 2]; }  // returns undefined
```

## 3. Defensive guards (when undefined is legitimately possible)

```js
// Optional chaining – renders nothing if undefined
items?.map(fn)

// Fallback to empty array
(items ?? []).map(fn)

// Strict check if it might be a non-array value
Array.isArray(items) ? items.map(fn) : null
```

In React you can also render a loading state:

```jsx
if (!items) return <p>Loading...</p>;
return items.map(...);
```

## 4. Recommended approach

1. Initialize array state with `[]`.
2. Verify the API response shape with `console.log`.
3. Use `?.` or `?? []` only where the value can genuinely be missing, so you don't hide real bugs.

If you share the code around the failing line (and where the data comes from), I can point to the exact cause.

### r33 · B

Bu hata, `.map()` metodunu `undefined` olan bir değer üzerinde çağırdığınız anlamına gelir. Yani `veri.map(...)` yazdığınızda `veri` o anda bir dizi değil, `undefined`'dır.

## Sık nedenler

1. **Veri henüz gelmedi.** React'te API'den veri çekiyorsanız, ilk render sırasında state henüz boştur.
2. **Yanlış özellik adı.** Örneğin `response.items` yazmışsınız ama API `response.data.items` döndürüyordur.
3. **Prop geçilmemiş.** Bileşene `items` prop'u gönderilmemiştir.
4. **Fonksiyon bir şey döndürmüyor.** `return` unutulmuş olabilir.
5. **Veri dizi değil.** Nesne ya da `null` geliyor olabilir.

## Çözümler

**1. Varsayılan değer verin**

```js
const [items, setItems] = useState([]); // undefined değil, boş dizi
```

**2. Prop için varsayılan değer**

```js
function Liste({ items = [] }) {
  return items.map(i => <li key={i.id}>{i.ad}</li>);
}
```

**3. Optional chaining ve fallback**

```js
(items ?? []).map(...)
// veya
items?.map(...)
```

**4. Koşullu render**

```jsx
{items && items.map(i => <li key={i.id}>{i.ad}</li>)}
```

**5. Gelen veriyi doğrulayın**

```js
console.log(items, Array.isArray(items));
```

Konsolda ne yazdığına bakın. API cevabını da kontrol edin: `console.log(response)` ile gerçek yapıyı görüp doğru yolu kullanın (örneğin `response.data.results`).

## Hızlı hata ayıklama

- Hata mesajındaki dosya ve satır numarasına gidin.
- O satırdaki `.map` öncesindeki değişkeni `console.log` ile yazdırın.
- Bu değişkenin nereden geldiğini (state, prop, API) geriye doğru izleyin.

**Not:** `?.` yalnızca hatayı susturur. Veri hiç gelmiyorsa asıl sorun başka yerdedir (yanlış URL, başarısız istek, yanlış alan adı). Bu yüzden kökünü de kontrol edin.

Kodunuzu ve hatanın geçtiği satırı paylaşırsanız, tam nedenini birlikte bulabilirim.

### r33 · C

Bu hata, `undefined` olan bir değer üzerinde `.map()` çağırdığınızda oluşur. Yani kodunuz bir dizi bekliyor, ama o anda ilgili değişken `undefined`.

**Olası nedenler ve çözümler**

```jsx
const [items, setItems] = useState([]); // undefined yerine boş dizi ile başlatın

// Render'da koruma:
{items?.map(item => <li key={item.id}>{item.name}</li>)}
```

3. **Props eksik.** Bir bileşene dizi prop'u geçilmiyorsa varsayılan değer verebilirsiniz:

```jsx
function List({ items = [] }) {
  return items.map(i => <div key={i.id}>{i.name}</div>);
}
```

4. **Yazım hatası.** `itmes.map` gibi bir yazım hatası olup olmadığını kontrol edin.

**Hızlı çözüm**

Dizinin her zaman var olduğundan emin olmak için:

```js
(data ?? []).map(...)
```

ya da `data?.map(...)` kullanabilirsiniz. Ancak bu yalnızca hatayı gizler; asıl sorun veri akışındaysa onu düzeltmek daha doğrudur.

**Hatayı bulmak için**

- Hatanın oluştuğu satırdan hemen önce ilgili değişkeni `console.log` ile yazdırın.
- Stack trace'te hangi dosya ve satırın gösterildiğine bakın.

**İSTEM:**

How does a transistor work?

### r15 · A

A transistor is a tiny semiconductor device that uses a small electrical signal to control a much larger current. That one ability lets it act as either a **switch** (the basis of all digital logic) or an **amplifier** (the basis of analog electronics).

## The raw material: doped silicon

Pure silicon conducts poorly. Engineers "dope" it with impurities:

- **N-type**: atoms like phosphorus add extra free electrons (negative carriers).
- **P-type**: atoms like boron create "holes," missing electrons that behave like positive carriers.

Where P and N regions meet, a **junction** forms. Carriers near it cancel out, leaving a thin "depletion region" that blocks current unless the right voltage is applied. Transistors are built by arranging these regions cleverly.

## Type 1: Bipolar Junction Transistor (BJT)

A BJT is a sandwich, either NPN or PNP, with three terminals: **emitter**, **base**, and **collector**.

- With no current into the base, the junctions block flow, so the transistor is **off**.
- A small current into the base lowers the barrier. Electrons from the emitter flood across the very thin base, and most get swept into the collector.
- The collector current is roughly 100 times the base current (this ratio is called gain, or β).

So a tiny base current controls a large collector current. That is **amplification**.

## Type 2: MOSFET (the one in your computer)

A MOSFET has a **source**, a **drain**, and a **gate**. The gate sits on top of the silicon but is separated from it by a very thin insulating layer (silicon dioxide or a modern high-k material).

- With no voltage on the gate, there is no conductive path between source and drain, so it is **off**.
- When a voltage is applied to the gate, its electric field attracts carriers into a thin **channel** just under the insulator, connecting source and drain, so it is **on**.

Because the gate is insulated, almost no current flows into it. It is controlled by voltage, not current, which makes MOSFETs extremely power-efficient and easy to shrink.

## Why it matters

- **As a switch**: on = 1, off = 0. Combine transistors and you get logic gates (AND, OR, NOT), then adders, memory, and full processors. A modern chip holds tens of billions of MOSFETs, each only a few nanometers across.
- **As an amplifier**: a weak signal (from a microphone, antenna, or sensor) applied to the control terminal produces a stronger copy at the output.

## A simple analogy

Think of a water pipe with a valve. The large flow through the pipe is the main current. A small, effortless turn of the valve handle is the control signal. The transistor is that valve, except it has no moving parts and can switch billions of times per second.

### r15 · B

Transistör, bir elektrik sinyalini yükseltebilen veya bir devreyi açıp kapatabilen yarı iletken bir elemandır. Çalışması, yarı iletken malzemelerin elektriksel iletkenliğinin dış etkenlerle kontrol edilebilmesine dayanır.

**Temel yapı**
Transistörler, farklı katkılanmış (dopant) üç bölgeden oluşur:
- Bipolar Jonksiyonlu Transistör (BJT): NPN veya PNP yapıdadır. Üç ucu vardır: emitör, baz ve kollektör.
- Alan Etkili Transistör (MOSFET gibi): kaynak (source), kapı (gate) ve drenaj (drain) uçları vardır. Kapı, elektrik alanıyla kanalın iletkenliğini kontrol eder.

**Çalışma prensibi (BJT örneği)**
Bir NPN transistörde emitör bölgesi çok katkılı n tipi, baz bölgesi çok ince ve az katkılı p tipi, kollektör ise n tipidir. Baz-emitör jonksiyonu ileri yönde polarize edilirse elektronlar emitörden baza geçer. Baz çok ince olduğu için elektronların çoğu baz tabakasını geçip kollektöre ulaşır; sadece küçük bir kısmı bazda birleşerek baz akımını oluşturur. Böylece küçük bir baz akımı, çok daha büyük bir kollektör akımını kontrol eder. Bu orana akım kazancı (β veya hFE) denir; I_C ≈ β · I_B.

**MOSFET örneği**
Kapıya uygulanan gerilim, kapı oksidinin altında bir elektrik alanı oluşturur. Yeterli gerilim (eşik gerilimi) uygulandığında kaynak ve drenaj arasında iletken bir kanal oluşur ve akım akar. Kapı gerilimi kanalın iletkenliğini ayarlar. Kapıda akım neredeyse hiç akmaz; bu yüzden MOSFET'ler çok düşük güç harcar.

**Kullanım alanları**
- Amplifikasyon: Zayıf bir sinyali büyütme (ses amplifikatörleri, radyo).
- Anahtarlama: Açık/kapalı durumlarıyla dijital mantık devreleri (0 ve 1). İşlemcilerdeki milyarlarca transistör bu işi yapar.

**Özet**
Transistör, bir kontrol girişindeki küçük değişiklikle çıkıştan geçen akımı ayarlayan bir "musluk" gibi düşünülebilir. Bu özellik hem sinyal yükseltmeyi hem de dijital bilgisayarların temelini mümkün kılar.

### r15 · C

A transistor is a tiny semiconductor device that works as either a switch or an amplifier: a small electrical signal at one terminal controls a much larger current flowing between two others. Billions of them make up a modern processor.

**The material: doped silicon**

Pure silicon conducts poorly. Engineers "dope" it with impurities to create two types:
- **N-type**: extra free electrons (negative charge carriers).
- **P-type**: missing electrons, called "holes" (behave like positive carriers).

Where N and P meet, a junction forms. It acts like a one-way gate, letting current pass easily in one direction but blocking it in the other.

**Bipolar junction transistor (BJT)**

A BJT has three layers, for example N-P-N, with terminals called emitter, base and collector.
- With no voltage at the base, the P-type layer blocks current from collector to emitter. The switch is off.
- Applying a small voltage and current to the base lets electrons flood from the emitter through the thin base into the collector.
- A small base current thus controls a much larger collector current, typically 50 to 300 times larger. That is amplification.

**MOSFET (the type used in computer chips)**

A MOSFET has a source, a drain and a gate. The gate is separated from the silicon by a very thin insulating oxide layer.
- With zero gate voltage, no conductive path exists between source and drain. Off.
- Applying a voltage to the gate creates an electric field that attracts electrons to the surface beneath it. This forms a conductive "channel" between source and drain. On.
- Because the gate is insulated, it draws almost no current. It only needs a voltage to change state, which is why MOSFETs are very power-efficient.

**What it does in practice**

- **As a switch**: fully off represents 0 and fully on represents 1. Combining transistors forms logic gates (AND, OR, NOT), which build up to adders, memory and entire CPUs.
- **As an amplifier**: in the middle range, the output current follows the input signal's shape but with greater magnitude. This is used in audio equipment, radio receivers and sensors.

**Why it mattered**

Invented in 1947 at Bell Labs, the transistor replaced bulky, hot, power-hungry vacuum tubes. It is small, cheap, fast, reliable and can be manufactured in enormous numbers on a single chip. Today's leading chips pack tens of billions of transistors, each only a few nanometers in critical dimensions, switching billions of times per second.

**One-line summary**: a transistor uses a small voltage or current at one terminal to open or close, or to scale up, a larger current path between the other two terminals.
